# VERA v2 demonstration

Use fictional facts. Open https://vera-newcomer-guide.fondfoam.chatgpt.site.

1. Choose **Study & settle** and submit the goal. Confirm BC, select SFU or UBC Vancouver, and optionally add Banking. Pick a priority.
2. Build the plan. Open a source and show the relevant campus and expense limits. Point out that this is preparation guidance, not a funding decision.
3. Complete the banking preparation task. Edit a task or write a note.
4. Choose **Review details**, open optional details, and change school service availability from unknown to no. Save. The affected settlement task is revised and flagged; unrelated banking completion remains.
5. Switch to **Français**. The same facts, tasks, completion and official references remain. Explain that the French text has not received human language review.
6. Save the Markdown plan or export JSON. Review its contents, clear the session, then resume the JSON. Source versions and age are checked against the current catalog; no fresh network fetch or AI consent occurs during import.
7. Show the banking/tax example or a parent benefits journey. CCB and related BC family benefit share one application route rather than duplicate tasks.

The public demo is explicitly **Offline guidance**. Do not present it as a live LLM conversation. For a configured local Python API, demonstrate consent and actual tool events only after `scripts/smoke_live.py` passes with a real model. Record the model, usage and latency; never substitute mock events.
